## 2. 已核对的具体设计

[Ai-InterviewCoach/controller.py](https://github.com/C0deRatoR/Ai-InterviewCoach/blob/main/controller.py) 将跑题、不会、模糊回答与高分分别映射到引导、提示、追问和提高难度，展示了小型显式规则控制思路。本项目只参考分离原则，本文定义的权重、分数范围和状态契约由本项目设计。

[GrillKit 架构](https://github.com/Forkfield/grillkit/blob/main/ARCHITECTURE.md) 描述先保存回答再进行长时间 AI 评价的流程，可用于理解事务边界。其定时与跳过计分规则不直接采纳；本项目明确未作答/跳过排除有效均值并披露覆盖。

[DeepInterview skills](https://github.com/ngoanpv/DeepInterview/tree/main/skills) 是 Markdown＋YAML 的岗位/级别知识包与评分标准。目录名为 skills 不代表自动满足课程要求；本项目每个 Skill 另有触发、执行和结构化契约。

## 3. 本项目定位

AI 提问和报告生成已有公开实现。本项目以课程要求为中心，重点验证：明确触发的四个 Skill、主动澄清、可解释长期记忆、证据对应评分、跨会话复练和真实测试。不能把这些重点表述成“其他项目都没有”或“首创”。
