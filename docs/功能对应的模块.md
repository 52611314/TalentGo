## 核心协作边界

1. 前端契约以接口文档为准，不直接使用数据库字段名猜测响应。
2. 路由只调用服务；服务通过 repositories 访问 ORM；跨表提交由服务统一管理。
3. 编排器在调用 Skill 前构造不可变输入，Skill 返回候选结果，由编排器校验并提交。
4. DeepSeek 与 Mock 实现同一模型接口；Mock 标识贯穿操作、评价、报告和导出。
5. 题库和 rubric 的版本记录在每次会话/评价快照中；修改知识文件不能悄悄改变历史分数。

- `database/migrations/versions/` 已有 0001_m1_foundation，当前仅用户、资料、同步幂等回执三张业务表。
