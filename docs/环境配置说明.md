## 环境与隔离

已验证 Windows PowerShell 7.6.9、Python 3.13.9、Node v24.13.0、npm 11.6.2、Git 2.48.1.windows.1、Docker Engine 28.1.1。Python 支持 3.12/3.13，Node 要求 ≥22.12；其他平台未验证。

后端 backend/.venv，uv 引导 .tools/bootstrap，前端 frontend/node_modules，均不提交。安装使用 backend/uv.lock、frontend/package-lock.json，不修改系统 Conda 库。

## 配置文件

| 文件 | 当前字段 |
|---|---|
| 根 .env | POSTGRES_DB=talentgo、POSTGRES_USER=talentgo_app、POSTGRES_PASSWORD、POSTGRES_PORT=6543 |
| backend/.env | APP_ENV、DATABASE_URL、TEST_DATABASE_URL、CORS_ORIGINS、LLM_PROVIDER |
| frontend/.env | VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1 |

setup.ps1 用 configure_local.py 创建缺失文件和随机数据库密码，已有配置保留，秘密不回显。真实 .env 不提交；.env.example 可提交但密码仅占位。手工密码中的特殊字符需 URL 编码。

后端固定读取 backend/.env，进程环境优先。DATABASE_URL 驱动为 postgresql+psycopg，端口必须 6543；TEST_DATABASE_URL 使用独立 talentgo_test，测试执行前检查 `_test` 后缀且不同于开发库。

APP_ENV=development/test；CORS_ORIGINS 为 JSON 数组，默认允许 localhost:5173 与 127.0.0.1:5173。LLM_PROVIDER 只是预留选项 mock/deepseek，当前没有任何模型调用。模型 Key、上下文预算、租约等字段待后续实现，不宣称配置即能力。

## 地址与数据

Web 127.0.0.1:5173，API 127.0.0.1:8000；PostgreSQL localhost:6543。容器以 postgres -p 6543 启动，127.0.0.1:6543 映射容器 6543，健康检查同端口。卷 talentgo_talentgo_pgdata 持久化，不在源码目录写数据库文件。

Compose 当前只有 db。初始化角色具备本地开发建库管理权限，尚未做公开部署所需权限拆分；不把本地配置用于生产。没有修改系统已有 PostgreSQL 实例。

## 身份与秘密

原始身份令牌仅在创建时返回一次，保存在浏览器 localStorage；服务器只保存 SHA-256 哈希。清空浏览器数据会失去身份访问能力，首版没有找回。不要将令牌写入日志、截图或第三方请求。

VITE_ 变量进入浏览器产物，不能保存数据库密码或模型 Key。端口冲突只报告，不擅自换端口或结束无关服务。公开部署前需要 HTTPS、限流、权限与恢复设计。
