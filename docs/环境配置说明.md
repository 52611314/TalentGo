## M3 当前配置（2026-11-13）

当前 API v0.3.0，迁移 head=`0003_m3_skills`。数据库仍为 PostgreSQL **6543**，现有配置与持久数据保留。下方 M1/M2 部分为历史背景；以本节说明当前模型行为。

在 `backend/.env` 配置，不要将真实 Key 写入源码、截图、文档或 Git：

```dotenv
LLM_PROVIDER=deepseek
LLM_API_KEY=在本机填写实际密钥
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-flash
LLM_TIMEOUT_SECONDS=60
LLM_MAX_TOKENS=2400
CONTEXT_MAX_CHARACTERS=48000
```

LLM_PROVIDER 只控制配置页的默认选择；POST /sessions 的 provider 才是本场的明确来源，默认 mock 保持旧客户端兼容。Mock 始终可选且不调用供应商、不计能力分。真实模型缺少 Key 时创建失败，不悄悄回退 Mock。LLM_API_KEY 支持 DEEPSEEK_API_KEY 别名，优先使用前者，避免同时设置冲突值。修改配置后重启后端。

Base URL 必须 HTTPS，不能含账号、密码、查询或片段。官方地址无需 /v1；兼容端点可自行指定带 /v1 的地址，但本轮只验证官方 DeepSeek。模型名不自动猜测或替换。会话创建时冻结 provider/model/base URL/Prompt/rubric；更换本机默认配置不改已有会话的模型。密钥不进入快照，轮换 Key 后旧会话可使用新 Key 继续。

超时配置范围 5—120 秒，单次生成含一次修复共享时间预算，每个流片段检查；网络读取最多等待 15 秒。取消是尽力中止，最后提交还会检查取消状态；不是保证瞬时终止。max_tokens 范围 512—4096；JSON 被截断不会当有效评价。上下文字符预算为保守预检，并非精确 tokenizer；当前题原文超限明确失败，不截断后打分。MOCK_CHUNK_DELAY 现也用于校验成功后的候选文本分段显示，不代表供应商首字时延。

GET /models/status 只返回配置存在性及模型名称，不证明 Key 有效或余额充足。401/402/429、网络、超时、协议及格式/证据失败均显示明确错误码。HTTPX 不转发上游错误正文到用户，不记录 Authorization 或内部推理。实际供应商流在服务端解析完整 JSON 后才发布可见文本与正式结果。

## 配置文件

| 文件 | 当前字段 |
|---|---|
| 根 .env | POSTGRES_DB=talentgo、POSTGRES_USER=talentgo_app、POSTGRES_PASSWORD、POSTGRES_PORT=6543 |

APP_ENV=development/test；CORS_ORIGINS 为 JSON 数组，默认允许 localhost:5173 与 127.0.0.1:5173。LLM_PROVIDER 只是预留选项 mock/deepseek，当前没有任何模型调用。模型 Key、上下文预算、租约等字段待后续实现，不宣称配置即能力。

## 身份与秘密

原始身份令牌仅在创建时返回一次，保存在浏览器 localStorage；服务器只保存 SHA-256 哈希。清空浏览器数据会失去身份访问能力，首版没有找回。不要将令牌写入日志、截图或第三方请求。

VITE_ 变量进入浏览器产物，不能保存数据库密码或模型 Key。端口冲突只报告，不擅自换端口或结束无关服务。公开部署前需要 HTTPS、限流、权限与恢复设计。
