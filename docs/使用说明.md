# 使用说明（目标交互）

## M4 当前增补（2026-11-13）

M4：在「训练记忆」新增目标/偏好/自述弱项；可纠正、确认或删除。弱项按精确主题匹配（例如浏览器基础），目标/偏好可跨主题，岗位/模式可限制。档案里的推断开关默认关闭，启用也只产生待确认候选。修改会使正在生成的旧结果失败，可重试原操作；历史问答/报告保留。在「复练与成长」查看来源任务、进入针对主题的配置；创建/打开不算完成，首题须产生有效非空最终评价且本场成功结束。分数记录按岗位/模式/rubric 分组，展示覆盖、模型和 Prompt，不能当作能力提升证据。

下方 M1/M2/M3 章节为历史基线，未来契约与当前实现的差异以本节、M4阶段报告和实际 OpenAPI 为准。

## M3 当前操作

在「面试练习」选择训练来源。Mock 使用固定规则且无分数；DeepSeek 会把本场画像与答案发送给配置的模型服务，进行真实提问和证据评价。Key 只由后端读取，页面不输入、不展示。已完成历史保留原来源，不把 Mock 当真实评分。

可以留空岗位/类型进入澄清，真实模型理解目标文字；已确认目标不会被模型覆盖。仍有歧义时用选项继续，压力模式必须另行同意。画像和训练配置成为本场快照；长期记忆尚未接入。

主答保存后，模型根据本题全部回答评价；模糊、跑题、关键错误或有实质缺口时，可在预算内追问。明确不会时最多给一次提示并引导再试；手动提示同样只允许一次。用过提示不会暗扣固定分，但报告明确标注。追问不作为新的主问题重复计权，难度限制在 1—3。

生成中显示“准备问题/核对评分证据/整理复盘”等阶段。等待服务端确认后才能答下一题；供应商输出经完整校验才显示，临时片段还不是正式问题。网络、余额、限额、超时或引用错误会保留已保存答案；使用「重试原操作」即可，不能重发同一答案。取消需要等待确认，服务端最长一次读取等待约 15 秒，迟到结果不会覆盖取消终态。

报告提供总分、五维有效平均、每题分数与理由、缺口、建议、提示标记、原文证据和覆盖。展开维度后点击“定位用户原文”可回查来源；复盘建议也链接到原题。总分按有效最终主问题平均，空值不是零分。查看 Skill 执行记录可核对版本、阶段、模型与实际返回用量，不展示内部推理。尚未提供长期记忆、任务、趋势、导出和反馈页面。

以下 M2 操作仅描述历史 Mock 规则；真实来源不按 50 字判断回答质量。模型反馈有误差，不能核实经历、诊断心理或预测录用。

## M2 历史 Mock 操作

从「面试练习」创建配置；岗位/类型不确定可留空，进入面试室后点击明确选项或用固定关键词补充。确认 ready 后开始，压力模式需先确认强度。当前使用固定 Mock 题目，短于 50 字的回答可能触发固定追问，最多按配置的 0—2 次；这不是回答质量判定。

回答后可等待、停止生成、重试原操作、请求一次提示、跳过、暂停/恢复、降低压力或提前结束。刷新保留正式问答，未提交草稿仅在本机保存；若提示上次请求未确认，使用「确认上次提交/创建」，不要手动重复输入。断流自动尝试重连，失败时手动刷新状态，不自动重发答案。

结束后显示实际问答、覆盖与 Mock 总结，不含能力分。训练记录只显示当前身份；可以重新进入未完成会话或查看完成总结。现阶段没有报告导出、长期记忆、成长评分、复练或反馈页面，下文相关内容仍是目标交互。


设计基线 v0.1，2026-11-13。**M1 可使用工作台、创建/切换匿名身份、编辑保存档案和刷新恢复。M2 已开放 Mock 面试、历史与总结，真实评分、长期记忆、复练与反馈仍待后续；下文这些扩展内容是目标流程。**

当前使用：打开 http://127.0.0.1:5173 ，点击建立档案→创建昵称→训练档案→填写并保存；刷新可继续读取。当前各身份凭证只保存在此浏览器，没有账号找回。

## 1. 首次使用

进入首页后创建匿名训练身份并填写昵称，可选择前端/后端、基础水平、技术栈、背景和训练目标。画像字段允许暂时留空；系统在开始面试前澄清必要项。

当前身份令牌在浏览器本机保存，不上传到第三方分析服务。首版不提供账号找回，清除浏览器数据可能丢失访问身份的能力。页面应明确说明这一点，不能声称拥有完整登录与恢复体系。

## 2. 开始训练

1. 选择技术面、行为面或压力面，设置主问题数量、难度和追问上限。
2. 目标不明确时回答澄清问题；可跳过非必要背景，不需上传简历。
3. 压力面先确认强度与退出方式；未同意时不能启动压力训练。
4. 点击开始后等待首题完整生成。临时流式文本显示“生成中”，成功提交后再启用回答框。
5. 输入回答并提交；生成期间避免重复提交。需要提示、跳过或结束时使用对应控件。

## 3. 面试中的控制

- 提示：获得一次辅助，报告标明使用过提示。
- 跳过：该题标记 skipped，不算零分，报告注明覆盖情况。
- 停止生成：请求取消当前操作，显示停止中，终结后可重试；已保存输入保留。
- 暂停：仅在无生成任务时进入 paused；恢复后继续原会话。
- 降低压力：压力面可下调强度，后续追问遵循新强度；不从文字判断用户心理。
- 提前结束：基于已有有效回答生成报告，明确标注未完成题量和材料不足。

关闭页面不会删除数据；刷新后读取服务端会话和操作。断线时先重新订阅原操作，不重新发送同一答案。后台进程中断导致任务失败时，界面提供显式重试，不假装任务仍在正常生成。

## 4. 查看报告

报告展示五维评价、题目覆盖、总分、答案依据、缺失点、优先建议和复练任务。若没有有效评价，显示“材料不足”，不显示假造的 0 分或完整能力结论。

评分仅用于训练反馈；技术题看题目相关概念与分析，行为题看叙述结构与具体性，压力题看回应与论据。报告不能证明经历真实，也不能预测录用。

Mock 模式必须醒目标记，导出也保留。不同面试模式/评分版本的成绩应分别显示，避免误导性比较。导出目标为 Markdown/JSON，PDF 不属于首版必做。

## 5. 管理画像、记忆和复练

在资料页查看长期目标、偏好和薄弱点及其来源。自动推断记忆默认关闭；开启后系统可以提出未确认弱项。用户可以确认、纠正和删除，下一次生成使用更新后的内容。

删除记忆不会回写旧报告或撤回已生成文本；新上下文不得继续读取已删除条目。运行记录仅显示 ID、版本与读取原因，不展示密钥或内部思维链。

从报告任务进入复练，系统带入目标薄弱点创建新会话。完成相应训练并生成有效评价后，任务才可标记完成。历史页查看同模式、同岗位、同评分版本的趋势。

## 6. 提交反馈与删除历史

反馈入口填写相关性、连贯性、建议可操作性、便利性、再次使用意愿（各 1—5）和自由意见。课程统计与原话引用分开征得同意。参与者无需提供真实姓名或不必要个人信息。

删除会话前需明确确认；运行中的会话先停止任务。删除会话及其派生报告、运行记录和来源记忆/任务，不删除无关训练。首版没有公开管理他人数据的页面。

## 7. 可用性要求

主要控件支持键盘，输入框保留未提交草稿；流式状态使用文本与标识，不只靠颜色；评分图提供文字表。错误消息给出下一步，如重试操作、检查配置或缩短输入，而不是仅显示“失败”。
