# 使用说明（目标交互）

设计基线 v0.1，2026-11-13。**M1 可使用工作台、创建/切换匿名身份、编辑保存档案和刷新恢复。面试、报告、长期记忆、复练与反馈入口均待后续实现；下文这些内容是目标流程。**

当前使用：打开 http://127.0.0.1:5173 ，点击建立档案→创建昵称→训练档案→填写并保存；刷新可继续读取。当前各身份凭证只保存在此浏览器，没有账号找回。

## 1. 首次使用

进入首页后创建匿名训练身份并填写昵称，可选择前端/后端、基础水平、技术栈、背景和训练目标。画像字段允许暂时留空；系统在开始面试前澄清必要项。

当前身份令牌在浏览器本机保存，不上传到第三方分析服务。首版不提供账号找回，清除浏览器数据可能丢失访问身份的能力。页面应明确说明这一点，不能声称拥有完整登录与恢复体系。

## 2. 开始训练

1. 选择技术面、行为面或压力面，设置主问题数量、难度和追问上限。
2. 目标不明确时回答澄清问题；可跳过非必要背景，不需上传简历。
3. 压力面先确认强度与退出方式；未同意时不能启动压力训练。
4. 点击开始后等待首题完整生成。临时流式文本显示“生成中”，成功提交后再启用回答框。
5. 输入回答并提交；生成期间避免重复提交。需要提示、跳过或结束时使用对应控件。

## 3. 面试中的控制

- 提示：获得一次辅助，报告标明使用过提示。
- 跳过：该题标记 skipped，不算零分，报告注明覆盖情况。
- 停止生成：请求取消当前操作，显示停止中，终结后可重试；已保存输入保留。
- 暂停：仅在无生成任务时进入 paused；恢复后继续原会话。
- 降低压力：压力面可下调强度，后续追问遵循新强度；不从文字判断用户心理。
- 提前结束：基于已有有效回答生成报告，明确标注未完成题量和材料不足。

关闭页面不会删除数据；刷新后读取服务端会话和操作。断线时先重新订阅原操作，不重新发送同一答案。后台进程中断导致任务失败时，界面提供显式重试，不假装任务仍在正常生成。

## 4. 查看报告

报告展示五维评价、题目覆盖、总分、答案依据、缺失点、优先建议和复练任务。若没有有效评价，显示“材料不足”，不显示假造的 0 分或完整能力结论。

评分仅用于训练反馈；技术题看题目相关概念与分析，行为题看叙述结构与具体性，压力题看回应与论据。报告不能证明经历真实，也不能预测录用。

Mock 模式必须醒目标记，导出也保留。不同面试模式/评分版本的成绩应分别显示，避免误导性比较。导出目标为 Markdown/JSON，PDF 不属于首版必做。

## 5. 管理画像、记忆和复练

在资料页查看长期目标、偏好和薄弱点及其来源。自动推断记忆默认关闭；开启后系统可以提出未确认弱项。用户可以确认、纠正和删除，下一次生成使用更新后的内容。

删除记忆不会回写旧报告或撤回已生成文本；新上下文不得继续读取已删除条目。运行记录仅显示 ID、版本与读取原因，不展示密钥或内部思维链。

从报告任务进入复练，系统带入目标薄弱点创建新会话。完成相应训练并生成有效评价后，任务才可标记完成。历史页查看同模式、同岗位、同评分版本的趋势。

## 6. 提交反馈与删除历史

反馈入口填写相关性、连贯性、建议可操作性、便利性、再次使用意愿（各 1—5）和自由意见。课程统计与原话引用分开征得同意。参与者无需提供真实姓名或不必要个人信息。

删除会话前需明确确认；运行中的会话先停止任务。删除会话及其派生报告、运行记录和来源记忆/任务，不删除无关训练。首版没有公开管理他人数据的页面。

## 7. 可用性要求

主要控件支持键盘，输入框保留未提交草稿；流式状态使用文本与标识，不只靠颜色；评分图提供文字表。错误消息给出下一步，如重试操作、检查配置或缩短输入，而不是仅显示“失败”。
